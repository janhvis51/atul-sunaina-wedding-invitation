# Atul — Groom-side wedding invitation

A separate React + Vite animated invitation website in a midnight navy and antique gold theme. It uses the same website format as the bride-side invitation: animated opening envelope, hero, countdown, event cards, music control and closing section.

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open Terminal and run:

```bash
npm install
npm run dev
```

3. Open the localhost URL shown by Vite.
